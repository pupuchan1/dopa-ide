# 🌈 dopa-ide

Claude Code を「ドパガキ仕様」にする mod です。Claude が働いている間も、終わった瞬間も、とにかく派手になります。

## できること

- **作業中**：プロンプトの上に黄色い帯が点滅し、進捗バー、今やっていること、経過時間、ツールの実行回数が出ます
- **コンボ**：ツールを 10 / 25 / 50 / 100 回使うと「🔥 COMBO!」が出て、効果音が鳴ります
- **完了したとき**
  - 🎆 花火と紙吹雪が上がり、虹色の「✨ COMPLETED! ✨」が出ます
  - ファンファーレが鳴り、「おつかれさま！完了しました」と読み上げます
  - 最後の回答と、そのターンのツール行が緑に光ります
  - デスクトップアプリでは、サイドバーの未読ドットが点滅し、セッション名の頭に ✅ が付きます（次のプロンプトを送ると外れます）
- **実行ログ**：帯にマウスを乗せるとこのターンの実行履歴が出ます。`/dopa-log` ならペインで全部見られます

ターミナルでもデスクトップアプリ（Code タブ）でも動きます。未読ドットとタイトルの ✅ は、デスクトップアプリ専用です。

## インストール

ターミナルで Claude Code を起動して、プロンプトに次の1行を入力します。

```
/plugin install dopa-ide --marketplace <owner>/dopa-ide
```

マーケットプレイスを追加するか聞かれたら `y` を押し、インストール先のスコープを選びます。ユーザー全体（user）にすると、デスクトップアプリの Code タブでも動きます。

## 開発

```
claude plugin validate .
claude plugin test .
```

手元のフォルダから直接読み込むなら、`claude --plugin-dir <このフォルダ>` で起動します。

## 音について

効果音は、mod の中で計算して作っています。音声ファイルは同梱していません。Windows では PowerShell を使って鳴らし、読み上げにはシステムの音声を使います。
